🎓 Headless Training Project

Complete Architecture & System Design

Unified API, Analytics Dashboard & Slack Integration

🏗️ Project Components

⚡

PlusPlus API Server

FastAPI HTTP endpoint (port 8000) that proxies training platform requests and unifies multi-source data.

📊

Streamlit Dashboard

Analytics UI (port 8501) displaying completion rates, budgets, engagement, feedback, and compliance metrics.

💬

Slack Bot Integration

Slash command `/plusplus` for on-demand training searches and enrollment links in Slack.

📚 Connected Training Platforms

Platform Integration Type Data Available
PlusPlus (Learn++) REST API via .env key Courses, events, assignments, enrollments, metrics
Pluralsight GraphQL API via .env key Course catalog, ratings, user progress, completion %
Trailhead MCP Server (auto OAuth) Salesforce cert catalog, modules, trails, badges
O'Reilly MCP Server (auto OAuth) Books, videos, courses, certifications, learning paths

⚡ PlusPlus API Server (main.py)

Runs on: localhost:8000 FastAPI server proxying requests to PlusPlus + integrating Trailhead, Pluralsight, O'Reilly via MCP
Key Endpoints
  • /api/courses — All training courses
  • /api/events — Upcoming training sessions
  • /api/enrollments — User enrollments
  • /api/assignments — User assignments
  • /api/search — Search PlusPlus catalog
  • /api/unified-search — Search all 4 platforms
  • /slack/slash — Slack integration endpoint

📊 Streamlit Dashboard (dashboard.py)

Five Analytics Sections
Section Key Metrics Data Source
Completion & Status Active, completed, overdue by dept PlusPlus
Budget & Cost Spend, cost/employee, ROI cost_mapping.json
Engagement & Reach Active users, training hours PlusPlus metrics

💬 Slack Integration

How It Works
  1. User types /plusplus search mulesoft in Slack
  2. Slack sends request to /slack/slash endpoint
  3. Server verifies signing secret & queries 4 platforms in parallel
  4. Results formatted as Slack message with enrollment links
  5. Posted back to user's channel or DM
Available Commands
  • /plusplus courses — List all courses
  • /plusplus events — List upcoming events
  • /plusplus search <query> — Search all platforms

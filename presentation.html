🎓 Headless Training Dashboard

Unified Analytics Platform for Enterprise Learning

Integrating PlusPlus, Pluralsight, Trailhead & O'Reilly

Project Overview

📊

What It Does

Aggregates training data from 4 platforms and displays comprehensive analytics on completion rates, costs, engagement, effectiveness, and compliance.

🎯

Who Uses It

L&D leaders, department managers, and executives tracking training ROI, budget spend, and employee skill development across the organization.

📚 Connected Training Platforms

⚡

PlusPlus (Learn++)

Org-wide tracking
Assignments, enrollments, adoption metrics

⭐

Pluralsight

Ratings & Progress
Course feedback, completion tracking

🏆

Trailhead

Salesforce Certs
Certification catalog (MCP)

📖

O'Reilly

Tech Learning
Books, videos, courses (MCP)

🏗️ System Architecture

Data Flow Pipeline
Training Platforms ↓ APIs (.env keys) ↓ platform_connectors.py (Aggregation Layer) ↓ Normalized Schema ↓ Configuration Files (Costs, Certs) ↓ Streamlit Dashboard (5 Analytics Sections) ↓ Live Browser UI (http://localhost:8501)

📈 Dashboard Sections

Section Metrics Data Source
1️⃣ Completion & Status Active, completed, overdue courses by department PlusPlus assignments
2️⃣ Budget & Cost Spend vs budget, cost-per-employee, ROI cost_mapping.json
3️⃣ Engagement & Reach Unique learners, active users, training hours PlusPlus metrics
4️⃣ Effectiveness & Feedback Ratings, pass rates, performance impact Pluralsight + manual
5️⃣ Compliance & Expirations Cert renewals, deadlines, status flags cert_expirations.json

🔄 How It Works

  1. User opens browser → http://localhost:8501
  2. Dashboard loads → Reads .env and config files
  3. Connectors initialize → Authenticate to 4 platforms
  4. Data aggregated → platform_connectors.py normalizes all data
  5. Live metrics displayed → 5 analytics sections render
  6. Admin panel edits → User can adjust cost mapping in real-time
  7. Charts & tables update → Full interactivity with filters & drill-downs
